# Nexora Gamepad para Android

Aplicación Android para enviar los controles por Wi-Fi al receptor de Windows.

## Objetivo
- Android 8.0 o posterior como objetivo inicial.
- Interfaz táctil con botones, cruceta, sticks y gatillos.
- Vibración háptica local configurable.
- Recepción de vibración generada por el juego en Windows: objetivo pendiente de integración y pruebas.

La app no necesita crear una cuenta. La conexión se configura mediante la dirección IP local del PC.
