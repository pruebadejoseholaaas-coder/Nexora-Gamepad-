# Perfil de teclado para PPSSPP

Nexora Gamepad incluye un modo alternativo de teclado para usar el teléfono con PPSSPP cuando no hay un controlador virtual XInput disponible.

## Activarlo

1. Ejecuta `NexoraGamepad.exe` en Windows.
2. Si el mando virtual no está disponible, el receptor pregunta si deseas activar el modo teclado.
3. Responde `s` para activarlo.
4. Abre PPSSPP y déjalo en primer plano.
5. En PPSSPP, entra en **Ajustes > Controles > Asignación de controles** y asigna las teclas de esta tabla.

| Control de Nexora | Tecla |
|---|---|
| A | J |
| B | K |
| X | U |
| Y | I |
| Cruceta | Flechas |
| L1 | Q |
| R1 | E |
| Select | Retroceso |
| Start | Enter |
| Stick izquierdo | W / A / S / D |
| Stick derecho | T / F / G / H |
| L3 | C |
| R3 | V |
| L2 | 1 |
| R2 | 2 |

En el stick izquierdo: arriba = W, abajo = S, izquierda = A, derecha = D. En el derecho: arriba = T, abajo = G, izquierda = F, derecha = H.

## Importante

- Este modo envía pulsaciones de teclado a la ventana que esté activa. Mantén PPSSPP en primer plano mientras juegas.
- No lo actives si no quieres que Nexora envíe teclas a la aplicación activa.
- El modo teclado no crea un mando virtual y no sustituye XInput. Es una alternativa para PPSSPP y otros programas que acepten teclado.
- Las teclas se liberan al soltar los controles, perder la conexión o cerrar el receptor.
- Los juegos PSP normalmente usan un solo stick analógico; el segundo stick puede no tener función en muchos juegos.
