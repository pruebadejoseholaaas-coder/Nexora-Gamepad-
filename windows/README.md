# Nexora Gamepad para Windows

Receptor local para los controles enviados desde Android.

## Requisitos previstos
- Windows 10/11 de 64 bits.
- Python 3.11 o posterior para ejecutar desde código.
- Una red Wi-Fi local compartida con el teléfono.
- Para crear un mando virtual XInput se necesitará un controlador virtual compatible. El instalador y su procedencia se documentarán antes de recomendar su instalación.

## Estado
La primera etapa es validar la comunicación local. La emulación de mando y la lectura de vibración de retorno se incorporarán por separado y se probarán antes de publicar una versión final.
